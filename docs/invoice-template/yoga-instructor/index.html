Invoicing tips for yoga instructors

  • List class dates or counts so studios can reconcile them with their schedule.
  • Bill private clients per session or per prepaid package and note any expiry date.
  • Show travel and studio rental as separate lines.
  • State your cancellation policy for private sessions.
  • Number invoices sequentially so repeat studios can track them.

Typical line items

  • Studio group classes, November (8 classes)
  • Private sessions package (5 sessions)
  • Travel to client home (private sessions)
  • Workshop, Saturday 2 hours

FAQ

Per class or per head?

Studios pay in different ways, such as a flat rate per class or a base plus a per-attendee amount. Confirm the basis before you start and show it on the invoice.

How do I invoice a class package?

Show the number of sessions and the package price, and note any expiry date. Many instructors invoice the package in advance.

Am I an employee or a contractor?

It depends on your agreement and local rules, which affect whether you invoice at all. Check local guidance if unsure.
