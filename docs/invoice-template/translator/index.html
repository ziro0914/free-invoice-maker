Invoicing tips for translators

  • State the language pair, word count basis (source or target) and the document name on every line.
  • If you offer CAT tool match discounts, show repetitions and fuzzy matches as separate lines with their reduced rates.
  • Set a minimum fee for short jobs, since a 50-word translation still involves setup and review.
  • Add rush surcharges for weekend or under-48-hour delivery, and agree on them before starting.

Typical line items

  • Translation French to English, marketing brochure (per source word)
  • Proofreading by second linguist (hourly)
  • Certified translation of birth certificate (per page)
  • Rush surcharge (48-hour delivery)

FAQ

Should I charge per source word or per target word?

Per source word is most common because the count is known before work starts, so clients can approve a fixed price. Per target word is used in some markets and for scanned documents where the source can't be counted easily. Either works; just state the basis clearly on both the quote and the invoice.

How do I invoice certified translations?

Bill certified translations per page or per document, with a separate line for certification, notarization or courier fees if applicable. What counts as a certified translation differs between countries and receiving authorities, so check local rules or the client's requirements. Include the document type and the receiving institution in the description for reference.

What is a minimum fee in translation?

A minimum fee is a flat charge for very short jobs, covering file handling, terminology checks and admin that take time regardless of word count. Many translators set a minimum equivalent to around an hour of work. Show it as a single line labelled minimum charge when the per-word total falls below it.
