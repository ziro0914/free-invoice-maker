How do I turn an hourly rate into a fixed project price?

Estimate the hours honestly, multiply by your hourly rate, add a buffer for revisions and surprises, then add any expenses you pass on. The result is your fixed price; a deposit is a share of it paid upfront.

How big should the buffer be?

There is no universal number. Many freelancers add roughly 10-20% for well-defined work and more when the scope is vague or the client is new. Spell out the number of revision rounds in the quote.
