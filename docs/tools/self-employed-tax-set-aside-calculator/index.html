How much should a freelancer set aside for taxes?

It depends on income, deductions, filing status and state. Many guides cite a rough 25-30% of net profit as a starting point, and some people need more. Use this calculator for a ballpark and confirm the real figure with the IRS or a tax professional.

How is self-employment tax calculated?

In the US it is generally 15.3% (12.4% Social Security plus 2.9% Medicare) applied to 92.35% of net self-employment earnings. This calculator ignores the Social Security wage-base cap and any additional Medicare tax, so check the current rules if your income is high.
