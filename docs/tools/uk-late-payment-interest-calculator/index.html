How is UK late payment interest calculated?

Under the Late Payment of Commercial Debts rules, interest on a late business-to-business invoice is simple interest at 8% above the Bank of England base rate. For example, on 2,000 pounds at a 4% base rate the rate is 12%, so 45 days overdue is 2,000 x 12% x 45 / 365 = about 29.59 pounds, roughly 0.66 pounds a day.

Which base rate and fixed sum should I use?

The base rate that applies is generally the one in force at a set reference date, so check the current gov.uk guidance rather than relying on this default. The fixed recovery sum depends on the size of the debt; the 70 pound default here is only a placeholder, so look up the gov.uk table. Rules differ for consumers, public bodies and other countries, and contract terms can change things, so check gov.uk or ask a professional before claiming.
